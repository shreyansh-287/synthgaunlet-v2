      SynthGauntlet Docs
      
            
      Multi-agent privacy & utility guide
      
          
      
        
      
        
      
      

      
      
      
        
        
        
      
          
      
            
      
              🛡️ Privacy Boundary & Security Guarantees
            
      
            Technical Controls
          
      
          
      
            • Zero Raw Row Transmission: Sensitive raw records are NEVER passed to any LLM prompt. Only anonymized statistical aggregates, column marginals, covariance matrices, and diagnostic deltas reach Gemini.
      
            • Deterministic Verification Gate: The LLM never grades its own work. All release gates, Kolmogorov-Smirnov distances, and attack breach metrics are computed 100% deterministically by mathematical code.
          
      
        
      

        
        
      
          
      
            🚀 How to Use SynthGauntlet
          
      
          
        
            
      1. Import Data: Upload CSV, TSV, XLSX, JSON, JSONL, or Parquet (up to 50,000 rows / 15 MB), connect BigQuery, or select a benchmark sample. Delimiters and nested JSON objects are normalized automatically.
        2. 
            
      2. Remediate PII: If the deterministic pre-scan finds likely direct identifiers, choose Mask, Drop, Salted Hash, or seeded synthetic replacement before profiling.
        3. 
            
      3. Inspect & Configure Columns: Confirm the inferred label, quasi-identifiers, output row count, synthesis engine, and release policy.
        4. 
            
      4. Forge & Attack: Launch the adversarial loop and watch Forge, Auditor, Challenger, and Arbiter evaluate multiple candidates over successive rounds.
        5. 
            
      5. Review the Scorecard: Inspect every utility and privacy gate, the Pareto frontier, differential-privacy statement, policy used, and fairness warnings.
        6. 
            
      6. Release & Verify: A certified run enables CSV and certificate downloads plus BigQuery export. Use Check certificate with the CSV and certificate PDF to detect any later change. If the gate fails, download the failure report PDF for the exact metrics and engine analysis. The CSV stays unavailable.
        7. 
          
      
        
      

        
        
      
          
      
            
      
              🤖 The Adversarial Agent Cast
            
      
            Google Cloud Vertex AI & Deterministic Math
          
      
          
      
            
      
              
      
                
      ⚗️ Forge (Synthesizer)
      
                Generator
              
      
              
      Runs Beam-Search Multi-Candidate Generation proposing 3 diverse plans per round along the Pareto frontier. Employs dependency-aware grouped sampling, copula rank preservation, and domain bound clamping.
      
            
      
            
      
              
      
                
      📏 Auditor (Utility Auditor)
      
                Evaluator
              
      
              
      Computes 2-sample Kolmogorov-Smirnov distances, Total Variation, correlation divergence ($|\Delta r| \ge 0.15$ broken relationships), SQL query equivalence, and Train-on-Synthetic Test-on-Real (TSTR) ML utility.
      
            
      
            
      
              
      
                
      🕵️ Challenger (Privacy Attacker)
      
                Adversary
              
      
              
      Executes an Adaptive Multi-Pass Tool Loop probing nearest-neighbor re-identification, shadow Membership Inference (MIA), outlier exposure, attribute inference, auxiliary linkage, and near-duplicate rows.
      
            
      
            
      
              
      
                
      ⚖️ Arbiter (Orchestrator)
      
                Judge
              
      
              
      Enforces mathematical release gates and Pareto candidate selection. Tracks multi-round state via a RunBlackboard, selects only gate-passing files for release, and can invoke deterministic Auto-Heal after ordinary rounds fail.

            🎛️ Deterministic Synthesis Engine & Knobs
          
      
          
      
            The multi-agent loop dynamically tunes synthesis parameters between rounds to eliminate privacy vulnerabilities while recovering domain utility:
          
      
          
      
            
      
              🔀 Recombination Dial (0.0 → 1.0):
              
      The primary privacy dial. At 0.0, records mirror real source records. At 1.0, attributes are recombined across independent records using conditional marginals, neutralizing re-identification.
      
            
      
            
      
              📈 Rank-Preserving Copula Jitter:
              
      Scaled noise jitter applied according to column covariance and standard deviation, protecting outliers while maintaining correlation ranks.
      
            
      
            
      
              🎲 Categorical Resampling & Rare Floor:
              
      Resamples categorical values from conditional marginals and clamps rare categories (<1% frequency) to prevent unique fingerprinting.
      
            
      
            
      
              🔒 Deterministic Fallback:
              
      If Gemini is unavailable or times out, the deterministic planner continues the bounded round sequence. Certification still requires every configured release gate to pass.
      
            
      
          
      
        
      

        
        
      
          
      
            
      
              📂 Multi-Format Upload & PII Pre-Gate
            
      
            Before Profiling
          
      
          
      
            
      
              
      Supported files
      
              
      CSV / TSV with delimiter detection, XLSX with sheet selection, JSON / JSONL with nested-key flattening, and Parquet. Nested lists become comma-separated text with a warning. Legacy XLS files should be saved as XLSX.
      
            
      
            
      
              
      Deterministic PII detection
      
              
      Scans for email, phone, SSN, IP address, URL, Luhn-valid payment-card patterns, sensitive column names, and highly unique ID-like columns. Examples shown in the modal are redacted.
      
            
      
            
      
              
      Available remediation
      
              
      Mask replaces values with a redaction marker; Drop removes the column; Salted Hash creates stable one-way tokens; and Synthetic Replacement uses seeded Faker values independent of the originals. Remediation happens locally before semantic profiling or synthesis.
      
            
      
          
      
        
      

        
        
      
          
      
            🧭 Synthesis, Rescue & Decision Support
          
      
          
      
            
      
              
      Differential Privacy Engine
      
              
      Choose Laplace DP to split an epsilon budget across one-way marginals and two-way tables that tie the label to its strongest columns. Numeric values are drawn inside each noisy bin, and later rounds redraw from that same release. Smaller epsilon adds more noise. The scorecard states a formal epsilon guarantee only when the released table remains on the pure DP path; a hybrid or Auto-Heal replacement displays No formal DP guarantee.
      
            
      
            
      
              
      Auto-Heal Rescue
      
              
      If all ordinary rounds miss the gate, Auto-Heal searches deterministic privacy-safe redraws, removes rows closest to training records, suppresses singleton quasi-identifier combinations, and can apply generalization or second-generation synthesis. Every candidate is rechecked by the Auditor, Challenger, and Arbiter. A repaired file becomes downloadable only after it passes every gate and is labeled CERTIFIED_AFTER_RESCUE.
      
            
      
            
      
              
      Pareto Privacy–Utility Frontier
      
              
      Every candidate from the current run is plotted by utility score and normalized privacy risk. The connecting line marks non-dominated candidates. Drag the slider or select a point to inspect it; download remains attached to a candidate that passed the release gate.
      
            
      
            
      
              
      Release Policy Controls
      
              
      Use Privacy first, Balanced, or Analytics first, or describe a custom priority. Only policy text is sent for interpretation—never source rows. The resulting numeric thresholds are displayed, validated, and enforced by deterministic code.
      
            
      
            
      
              
      Fairness & Representation Advisory
      
              
      The scorecard compares representation and outcome behavior for detected groups and reports warnings when disparities merit review. Fairness is an advisory signal: it does not override the deterministic privacy-and-utility release gate and does not independently block download.
      
            
      
          
      
        
      

        
        
      
          
      
            
      
              📜 Signed Certificate & Tamper Verification
            
      
            Certified Runs Only
          
      
          
      
            
      
              
      1. Evidence record
      
              
      The branded two-page PDF records the run, policy, DP statement, row counts, every gate result, synthesis and attack method, SHA-256 fingerprints, and issue time.
      
            
      
            
      
              
      2. Digital sealing
      
              
      The synthetic CSV is fingerprinted with SHA-256. The canonical certificate record is signed with HMAC-SHA256 and embedded inside the PDF alongside a verification QR code.
      
            
      
            
      
              
      3. Check certificate
      
              
      Upload the downloaded CSV and certificate PDF. VALID means both signature and fingerprint match; TAMPERED means a certificate field or CSV byte changed.
      
            
      
          
      
          
      The certificate supplies technical evidence for the tested file. It does not constitute legal HIPAA, GDPR, or regulatory certification. Re-saving a CSV can change its byte-level fingerprint even when displayed values appear unchanged.

            TableData & Export API

      • Supports all 350+ Google BigQuery Public Datasets (e.g. bigquery-public-data) with zero-cost table sampling via the TableData API.
        • 
              
      • Supports private datasets by signing in with your Google account or granting the host Service Account the BigQuery Data Viewer role.
        • 
              
      • Deep Nested Type Normalization: Automatically detects and serializes complex BigQuery ARRAY, STRUCT, REPEATED records, GEOGRAPHY, and BYTES into clean, hashable JSON strings.
        •

      • Click Export to BigQuery directly on the scorecard or from any session in History.
        • 
              
      • Automatically creates destination datasets if missing and writes tables using WRITE_TRUNCATE.
        • 
              
      • Requires BigQuery Data Editor and BigQuery Job User roles on the target project.
        • 
            
      
          
      
        
      

        
        
      
          
      
            ⚙️ System Boundaries & Ingestion Limits
          
      
          
      
            
      
              📂 Source Data Ingestion (Input):
              
      Supports CSV, TSV, XLSX, JSON, JSONL, and Parquet uploads up to 50,000 rows / 15 MB and BigQuery sample imports up to 10,000 rows.
      
            
      
            
      
              ✨ Rows to Forge (Output):
              
      Strictly enforced: Min 500 rows · Max 10,000 rows (< 500 synthetic rows degrades ML utility & statistical auditing power).
      
            
      
            
      
              🔄 Adversarial Pass Cap:
              
      Up to 5 configured rounds with multi-candidate Pareto beam search, followed by optional Auto-Heal rescue attempts. A run may finish uncertified.
      
            
      
            
      
              🔒 Privacy Defense:
              
      Automated re-identification, membership, outlier, attribute-inference, auxiliary-linkage, and near-duplicate defenses. Failed certification hides CSV, BigQuery, and certificate hand-off.
